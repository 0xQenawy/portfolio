Problem

Technical hiring assessments often test memorization over real understanding. Existing platforms reward pattern-matching and rehearsed answers rather than surfacing genuine problem-solving ability.

Solution

Built an AI-powered assessment platform focusing on Secure Product Design and scalable Software Architecture. The platform generates slightly flawed code so candidates must demonstrate genuine understanding to correct issues.

Outcome
